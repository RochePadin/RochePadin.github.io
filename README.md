# Roche Cooper M. Padin | Portfolio

A modern, responsive personal portfolio website for a BSIT student and aspiring full-stack developer. This project showcases technical skills, featured projects, credentials, education timeline, and a contact portal in a polished single-page experience.

## Live Portfolio

Open `index.html` in a browser to view the site locally, or serve it using a simple local web server.

## Overview

This portfolio highlights:

- A hero section introducing the developer and core focus
- Skills and technologies in a gamified bento-grid layout
- Featured project cards with GitHub links and tech stacks
- Certification and credential showcase
- Experience and education timeline
- Contact portal with direct email and social links
- Light/Dark theme toggle
- Animated and interactive UI design

## Featured Projects

### 1. Movie Browser
A React + Vite movie browsing app using TMDB API and Appwrite TablesDB.

- Live movie search
- Trending movie discovery
- Search analytics integration
- Modern UI with responsive layout

### 2. Event Management System
A RESTful ASP.NET Core 8 API for event registrations, ticketing, payments, and cancellations.

- .NET 8 backend
- SQL Server database
- EF Core integration
- AutoMapper setup

### 3. School Supplies PMPS
A PHP-based school supplies inventory and pricing system.

- Inventory tracking
- Pricing algorithm logic
- Customer ordering workflow
- Team project collaboration

### 4. Product Performance Checker
A PHP-based sales and product performance tracking web app.

- Daily and weekly product monitoring
- Transaction batching
- Sales performance reporting
- JavaScript-enhanced interactions

## Getting Started

### Option 1: Open directly

1. Navigate to the project folder.
2. Open `index.html` in any modern browser.

### Option 2: Run with a local web server

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
